# 🕒 Digital Clock using Python

## 📌 About the Project
This is a simple Digital Clock project created using Python and Tkinter. It displays the current time and date in a graphical user interface (GUI).

## ✨ Features
- Displays the current time.
- Shows AM/PM format.
- Displays the current date.
- Updates the time every second.
- Simple GUI with a yellow background.

## 🛠️ Technologies Used
- Python
- Tkinter
- Time Module

## 🚀 How to Run

1. Install Python on your system.
2. Save the code in a file named `digital_clock.py`.
3. Open your terminal or command prompt.
4. Run the following command:

```bash
python digital_clock.py
```

## 📸 Output
The application displays a digital clock with the current time and date.
